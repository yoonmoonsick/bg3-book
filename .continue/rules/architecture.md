# 프로젝트 아키텍처 가이드 (bg3-book)

이 프로젝트는 TypeScript 기반의 Node.js 프로젝트입니다. 에이전트 작업 시 아래 구조를 참고하세요.

## 📂 주요 디렉토리 구조
- `/src`: **모든 소스 코드가 위치한 핵심 폴더입니다.** 로직 수정 및 추가는 이곳에서 진행합니다.
- `/out`: 빌드된 결과물이 저장되는 폴더입니다. **이 폴더의 파일은 직접 수정하지 마세요.**
- `/.continue/rules`: 프로젝트 작업 규칙 및 컨텍스트가 정의된 곳입니다.
- `/node_modules`: 외부 라이브러리 폴더입니다. **인덱싱 및 분석에서 제외합니다.**

## 🛠 작업 규칙
1. **소스 코드 우선:** 모든 코드 수정 제안은 반드시 `/src` 폴더 내의 `.ts` 파일을 대상으로 합니다.
2. **의존성 관리:** 새로운 패키지 추가가 필요할 경우 `package.json`을 먼저 확인하세요.
3. **테스트:** 테스트 코드는 `/src/test` 또는 `/out/test` 관련 설정을 참고하여 작성합니다.

## 🚫 제외 대상 (Ignore)
- `/node_modules`, `/.git`, `/out` 폴더의 내용은 분석 범위에서 제외하여 토큰을 절약하세요.
